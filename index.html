AWS VPC Peering Lab

Private communication between two Amazon VPCs

Project by Aryan Wasekar

Project Overview

This project demonstrates private network communication between two AWS Virtual Private Clouds using VPC Peering, EC2 instances, route tables, and security groups.

Architecture

VPC A: 10.10.0.0/16

VPC B: 10.20.0.0/16

App-A: 10.10.2.10 (private IP)

App-B: 10.20.1.10 (private IP)

The VPC peering connection and route tables allow traffic between the two private networks, subject to security rules.

Technologies Used

  • Amazon VPC and VPC Peering
  • Amazon EC2
  • Public and private subnets
  • Route tables and security groups
  • Linux SSH and ICMP ping testing

Test Results

App-A successfully pinged App-B at 10.20.1.10, receiving 4 packets with 0% packet loss during the recorded test.

This demonstrates private IP connectivity between the VPCs.
